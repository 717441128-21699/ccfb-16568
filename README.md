# 港口引航模拟器（Harbor Pilot Simulator）

驾驶万吨货轮，沿航道把船引进港池、靠上码头的船舶操纵模拟游戏。
操纵运动严格按 **MMG 三自由度船舶操纵运动方程**求解，渲染用 **WebGL2**，全部逻辑用 **TypeScript**。

## 玩法

你是引航员，登船后通过**车钟、舵令、三艘拖轮**把船从航道外引进港池靠泊：

- **车钟**：退四～进四共 9 档，主机带响应延迟，停车后船凭惯性继续滑行数倍船长
- **舵令**：左/右满舵 35°，舵机以固定舵速转动；停车淌航时舵效急剧下降
- **拖轮**：船首/船中/船尾三艘，可顶推或拖拉、功率可调，用于横移、掉头、纠偏
- **应急锚**：极端情况下抛锚制动

任务失败/扣分点：靠泊法向速度超过 **0.15 m/s** 即判撞击码头、浅水区速度过高触发 squat 触底、驶出航道、靠泊角度过大、超时。

## 四个页面

| 页面 | 内容 |
|---|---|

| 驾驶台 | WebGL2 三维视口（尾随/环绕/俯视/驾驶台四视角）、HUD 仪表、车钟舵令拖轮控制台、2D 小地图、事件日志 |

## 物理模型

`src/core/` 下是与渲染完全解耦的纯物理层，可在 Node 下独立运行测试。

### 操纵运动方程（MMG）

随船坐标系三自由度（纵荡 u、横荡 v、艏摇 r），力按模块分解：

```
X = X_H(船体水动力) + X_P(螺旋桨) + X_R(舵) + X_风 + X_拖轮
Y = Y_H + Y_R + Y_风 + Y_岸壁 + Y_船间 + Y_拖轮
N = N_H + N_R + N_风 + N_岸壁 + N_船间 + N_拖轮
```

- **船体水动力**：Kijima 类通用回归导数（Yv、Yr、Nv、Nr 及三阶非线性项），按方形系数 Cb、B/d、L/B 估算，各船另有标定乘子
- **螺旋桨**：伴流分数 wP、推力减额 tP、进速系数 J、正倒车推力系数
- **舵力**：Fujii 法向力系数、螺旋桨尾流加速、停车失舵效应、船体干扰 aH
- **质量矩阵**：含纵/横/艏摇附加质量与重心耦合，浅水时附加质量增大
- **积分**：RK4 定步长（0.5s），含离心项的完整 MMG 运动方程

### 环境效应

- **浅水**（`shallow.ts`）：h/T 驱动附加质量、横阻尼、艏摇阻尼、阻力增值与舵效折减；Barrass 类公式算船体下沉 squat 与 UKC
- **岸壁效应**（`bank.ts`）：一侧水流加速产生吸力 + 船首被推开的力矩，随岸距指数变化
- **船间效应**（`interaction.ts`）：交会/追越时互相吸引、纵向错位产生转首干扰
- **风**（`windcurrent.ts`）：Isherwood 风格风载荷，用相对风攻角
- **流**：全部水动力以相对水速度 (uR, vR) 计算，天然包含流压
- **拖轮**（`tugs.ts`）：一阶惯性响应（时间常数 3s），按排水量配系柱拉力

直径分别增大到 1.91 / 1.84 / 1.75 / 1.49 倍——浅水旋回圈明显变大。

| 船型 | 仿真 | 手册 | 偏差 |
|---|---|---|---|
| 汊河号 | 7.57 L | 7.5 L | 0.9% |

其余检查：靠泊 0.12 m/s 平稳贴上、0.20 m/s 判撞击；三拖轮满功率 60s 横移响应达标；VLCC 浅水 squat 0.33m；右舵正确产生顺时针转首。

- **船型**：汊河号杂货船、苍岭号散货船、云衡号集装箱船、鲸海号 VLCC
- **港口**：临澜河港（河口浅水窄航道）、东港新港（深水集装箱枢纽、有横流交会船）、黑石屿油港（开敞岛港、VLCC 专用）

## 开发与测试

```bash
npm install
npm run dev          # 本地开发服务器
npm run build        # 类型检查 + 生产构建
npm run selfcheck    # 物理标定 24 项（旋回/冲程/撞击阈值/拖轮/squat）
npm run smoke        # 5 任务端到端冒烟（无 DOM，Node 跑完整操纵）
npm run berthing     # 三阶段自动驾驶靠泊闭环（验证 berthed/collision/评分）
npm run integration  # Playwright 浏览器集成（WebGL2 渲染、UI 交互、零控制台错误）
npm test             # 跑前三个 Node 测试
```


## 关键设计取舍

- **坐标系**：大地系 x 东、y 北、z 天；船体系 u 沿船首、v 左舷为正、r 逆时针为正。渲染统一 Z-up。
- **符号约定**：右舵 δ>0 产生顺时针转首（r<0），由 selfcheck 的右舵试验守护，防止回归。
- **标定方法**：通用回归给出导数量级，再用 `nrCalib` 等单船乘子把旋回直径校准到 3～5L，所有系数调整都由自动化测试验证而非手调。
- **性能**：物理定步长 0.5s、RK4，游戏以 4 倍速运行兼顾实船操纵的缓慢节奏与可玩性。
